# Falsification Framework — Pass 39
**Date:** 2026-11-24

## Distinctive claim under test
The Holobiont's connective tissue should allow heterogeneous specialist organs to transfer useful information that the receiver does not already possess, with a better total utility/cost/risk profile than text, typed structured evidence or receiver self-generation.

## Positive evidence required
A result counts only if:
1. True-example payloads outperform deranged/mismatched payloads on a receiver-necessity task.
2. The sender payload outperforms receiver-generated self-substitution at matched compute.
3. The effect replicates across multiple model pairs and held-out tasks.
4. The benefit survives independent verification and randomized evidence ownership.
5. Total bytes, memory, latency, adapter training and security costs are included.
6. The latent/hybrid protocol preserves specialist diversity and does not suppress useful minority evidence.
7. Integrity and fallback controls work under declared transport and endpoint threat models.

## Falsification or narrowing conditions
- If true and deranged payloads are practically equivalent when the receiver lacks the sender's evidence, the channel has not demonstrated example-specific transfer for that regime.
- If a receiver-generated message is equally useful at matched compute, the separate sender's unique value is not established.
- If gains survive derangement but disappear against no-message, the effect is a generic interface/computation effect rather than evidence of transmitted content.
- If the bridge fails on held-out model pairs or updates and requires costly retraining, classify it as pair-specific.
- If typed structured evidence matches or beats latent transfer on total cost, auditability and utility, latent transfer is not justified for that task.
- If payload integrity, endpoint trust or privacy risks cannot be bounded, restrict the channel to low-risk settings or disable it.
- If repeated communication collapses independent specialist responses and worsens fault diversity, the connective tissue is undermining another core Holobiont objective.

## Mandatory controls
- true vs deranged;
- true vs intact-no-private;
- true vs zero;
- moment-matched random;
- current sender vs receiver self-generation;
- sender ablation and evidence ownership swaps;
- same-family and cross-family transfer;
- transport tampering and signed malicious endpoint;
- text/typed/hybrid baselines;
- held-out task families and model versions.

## Interpretation rule
Do not call a latent payload a "thought" or claim shared understanding based on activation similarity, probe accuracy, attention maps or an aggregate benchmark delta. Use operational language: encoded information, receiver sensitivity, example-specific causal effect, task utility and separate-agent marginal value.
