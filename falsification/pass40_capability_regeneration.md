# Falsification Framework — Pass 40
**Date:** 2026-11-25

## Distinctive claim under test

The Cognitive Holobiont's surviving organs can help restore a missing specialist's capability after the specialist itself is removed, using only information genuinely retained by the remaining federation.

## Positive evidence required

A result supports the claim only if:
1. The target specialist's weights, adapters and privileged target artifacts are inaccessible to the recovery system.
2. The surviving-information manifest is complete and auditable.
3. The recovered specialist improves over a strong generalist and retrieval fallback.
4. Peer-specific retained information adds value over compute-matched self-generated data.
5. The gain survives randomized ownership swaps and held-out capability slices.
6. Rare, OOD, calibration, safety and adversarial behavior are tested independently.
7. No undeclared checkpoint, teacher endpoint, training data or evaluator leakage is used.
8. Total training, inference, storage, communication and verification costs are counted.
9. The recovery route remains safe when one repair dependency is corrupted.
10. An independent evaluator—not the recovery hypernetwork itself—accepts reintegration.

## Falsification or narrowing conditions

- If peer-assisted recovery does not beat the strongest fallback under matched resources, the distinctive regeneration claim is unsupported for that task family.
- If recovery gains disappear when a hidden base checkpoint, source adapter, teacher API or cached answer set is removed, the method is restoration/distillation, not peer regeneration.
- If the result improves common benchmark accuracy but loses rare or safety-critical capabilities, it is not successful regeneration.
- If the recovered model merely copies stored answers and fails on held-out compositions, it has not recovered the underlying capability.
- If the hypernetwork's own corruption disables all repair routes, the system has a common-mode recovery failure.
- If exact weights are claimed but only behavioral equivalence is measured, the claim must be downgraded.
- If no-information controls recover equally well, the claimed peer contribution is not established.

## Null-result policy

A failed recovery is a valid research outcome. Do not restore a hidden backup, query the deleted specialist, or reintroduce removed data after the declared deletion. Report the failure and update the information-survival boundary.

## Success criterion

The minimum meaningful success is reproducible, peer-specific improvement over the best non-peer fallback on a held-out capability distribution after the target checkpoint and its privileged training artifacts have been removed, with no unacceptable safety or calibration regression.
