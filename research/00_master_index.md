# Master Research Index

## Status

Research program initialized. This index is the navigation point for the long-horizon investigation.

## Core question

Can a heterogeneous distributed neural architecture combine specialist cognition, learned latent communication, shared knowledge, independent representations, distributed memory, fault tolerance, regeneration, and safe recursive self-rearchitecture into a system that provides capabilities beyond conventional monolithic, MoE, ensemble, and multi-agent architectures?

## Research discipline

1. Treat the treatise as the originating hypothesis/specification.
2. Verify every substantive claim against external evidence.
3. Search for contradictory evidence as deliberately as supporting evidence.
4. Follow citation chains rather than relying on isolated papers.
5. Distinguish established results from inference and speculation.
6. Do not implement a mechanism until its scientific assumptions and falsification tests are understood.
7. Record failed hypotheses and negative results instead of deleting them.
8. Revisit previous conclusions when new evidence changes the balance.

## Evidence taxonomy

| Label | Meaning |
|---|---|
| Established | Strongly established by convergent evidence |
| Strongly supported | Substantial evidence but not fully settled |
| Partially supported | Some components supported; important gaps remain |
| Plausible hypothesis | Technically plausible but insufficient direct evidence |
| Weakly supported | Limited or low-confidence evidence |
| Unsupported | No adequate evidence found |
| Contradicted | Credible evidence conflicts with the claim |
| Speculative | Primarily conjectural |
| Philosophical / conceptual | Not directly empirically testable in current form |
