# Open Problems — Pass 16 Addendum

1. Can a coalition reliably compute a function that no single member can compute because the required information is partitioned across members?
2. What is the minimal communication protocol that preserves useful independence while enabling integration?
3. Can graph interventions establish causal value of topology rather than confounding topology with agent roles/prompts?
4. How should conditional information value be estimated online without revealing the very private information being valued?
5. How can provenance and authorization survive latent/internal communication and multi-hop delegation?
6. Can a Holobiont remain useful when some specialists are noisy, compromised, colluding, or unavailable?
7. Is any resilience advantage independent of simply adding redundancy/compute, or is it reducible to an expensive ensemble?
8. Can repair restore unique capabilities after loss, or only patch behavior using surviving information?
