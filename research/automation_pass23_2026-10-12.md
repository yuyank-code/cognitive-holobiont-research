Updated status: communication volume alone is contradicted as a general solution; long-horizon failures are supported in tested settings; information seeking needs authorization constraints; memory needs provenance, scope, validity and contradiction handling; transcript-only audits are insufficient; graph attribution requires intervention validation; Holobiont-specific synergy remains unvalidated.

Proposed controller: independent exploration → epistemic ledger → authorization-aware query planning → minimal disclosure → provenance-bearing admission → versioned temporal memory with contradiction links and retraction → independent challenge with distinct evidence lineage → action-grounded verification and causal audit → safe fallback.

Falsification: compare best feasible single agent, full-information diagnostic, independent ensemble plus selection, fixed communication, unrestricted exchange, verified shared context, adaptive elicitation without memory governance, and adaptive elicitation with governed memory.
