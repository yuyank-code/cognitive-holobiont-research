# Claim–Evidence Matrix Addendum — Pass 28 (2026-10-18)

| Claim | Evidence added | Status |
|---|---|---|
| Nominal agent count is equivalent to independent evidence | Ringelmann preprint proposes dependence-adjusted effective team size but assumes exchangeable-style correlation and has bounded core task scope | Rejected as default assumption; proxy useful within scope |
| Answer entropy measures useful collective diversity | Distinct wrong answers can inflate entropy while correctness dependence remains high | Rejected; measure diversity, dependence, and utility separately |
| Debate gains grow monotonically with rounds/team size | Ringelmann, Revisiting MAD, and Talk Isn't Always Cheap report saturation or task/model-dependent regressions | Contradicted as a general rule |
| Heterogeneity reduces dependence and improves performance | Selected heterogeneous-team results reduce fitted redundancy parameter | Supported in tested settings; generality open |
| A fitted scaling curve establishes causal synergy | Fit predicts structural proxies, not causal net utility of the Holobiont architecture | Rejected |
| Persistent memory has no value after a benchmark null | Memory preprint reports null where independent items offer little reusable state; broader efficacy explicitly untested | Not supported; use memory-relevant longitudinal tasks |
| Agent decomposition and persistent memory are the same benefit | Lower peak per-call KV and persistent trace recall are distinct; cumulative traffic can rise | Contradicted |
| Protocol selection is inconsequential | ProtocolBench reports scenario-specific latency/completion/recovery differences | Contradicted in tested scenarios |
| Adaptive routing is universally beneficial | Router gains are scenario-specific and must be net of router cost | Unvalidated universally |
| Holobiont-specific synergy beats best feasible baseline | No complete resource-/information-/privacy-matched intervention-validated comparison | Still unvalidated |

Keep separate: nominal team size; correctness dependence; answer diversity; decisive information recovered; verified task utility; protocol/topology effect; memory reachability and temporal correctness; fault recovery; total resources, privacy leakage, and benign-evidence false rejection.
