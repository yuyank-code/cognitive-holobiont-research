# Claim–Evidence Matrix Addendum — Pass 34 (2026-11-19)

| Holobiont claim or design hypothesis | New evidence | Boundary / contradiction | Updated status |
|---|---|---|---|
| Continuous inter-organ communication makes the whole resilient | When Messages Go Wrong studies >29,000 executions and shows communication faults can propagate silently | Open-ended messages can remain parseable while losing essential content; the study is a preprint and not a trained organ federation | Communication needs explicit integrity and evidence contracts; continuous sharing alone is not resilience |
| More edges mean more fault tolerance | Flat topology retains 53.0% success versus 3.3% sequential and 3.2% hierarchical under the study's faults | Benefit is concentrated after evidence branching; fails when the fault occurs upstream of the branch or affects all paths | Conditional support for alternate paths; distinguish route diversity from independent evidence |
| Shared bloodstream should broadcast compact context to all organs | RCR-Router selectively routes role/task-stage-relevant shared memory, reporting 35% fewer tokens and 38% lower runtime than Full-Context | Does not test latent broadcast, long-term autobiographical memory, or adversarial provenance | Selective context routing is a strong baseline and likely default; latent broadcast remains unproven |
| A single communication format should connect organs | Routed Graph Handoff uses a router to select typed graphs or natural language; graph-only regresses on AppWorld while hybrid avoids the regression | Four benchmarks and 1,050+ trajectories; does not compare hidden-state bridges | Hybrid typed + natural language should be baseline; format selection is task-dependent |
| The Heart should activate all relevant specialists dynamically | RouterHGC uses a heterogeneous graph to select roles, models and collaboration modes; reports 0.80–6.17% accuracy gains on MATH/HotpotQA and 27.4% lower inference cost | Five datasets; no component-failure or long-horizon memory test | Supports task-conditioned routing, not full Holobiont superiority |
| Agent reliability can be judged from final task success | AgentChaos shows API crash, omission and value faults can reduce pass@1 by up to 50 pp; diagnosis remains weak | One system per architecture pattern; sparse per-configuration fault samples and unified reimplementation | Need process traces, stage-level validation, and silent-failure metrics |
| Retrying a failed task is self-healing | Repair or Resample reports 6.90% repair for unguided reruns and 20.15% for symptom-driven interventions | Preprint; limited frameworks and trajectory-level repair | Retry is not repair; causal localization and intervention anchors are required |
| Duplicate communication paths preserve knowledge | When Messages Go Wrong shows alternate path helps only if it already holds required evidence; fresh reacquisition helps when unaffected evidence remains | Duplicate copies from the same corrupted source do not restore information | Evidence ancestry and source independence must be tracked |
| Latent bridges are the best connective tissue | New peer-reviewed structured/hybrid communication results offer strong low-cost baselines | None of these studies tests latent bridges directly | Latent communication must beat selective structured/hybrid baselines under matched budgets |
| Fault-aware adaptation can make the network self-healing | The combined evidence supports routing, fault injection, evidence reacquisition and trace-based intervention as separate primitives | No study demonstrates a persistent self-organizing Holobiont with all primitives integrated | A plausible staged architecture hypothesis; integration and emergent benefits remain open |
