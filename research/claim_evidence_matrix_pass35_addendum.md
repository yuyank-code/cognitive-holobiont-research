# Claim–Evidence Matrix Addendum — Pass 35 (2026-11-20)

| Holobiont claim or design hypothesis | New evidence | Boundary / contradiction | Updated status |
|---|---|---|---|
| A shared memory store creates collective memory | From Private Experience to Collective State (2026 survey) distinguishes persistence, accessibility and governed reliance; shared access is neither necessary nor sufficient for collective state | Curated 89-paper preprint survey; taxonomy is a synthesis, not a causal experiment | Reframe: measure durable cross-agent reliance, not storage topology |
| The Hippocampus can preserve a shared narrative | UMA (EMNLP 2026) supports proactive structured memory maintenance in a single-agent one-to-many setting | Single agent, fixed tools; synthetic Ledger-QA and no multi-agent state governance | Bounded support for proactive memory; no federation result |
| Memory should be retrieved by semantic similarity | AMA-Bench (ICML 2026) finds causal/objective information is often missed by similarity retrieval; causal-graph AMA-Agent reports 57.22% accuracy, +11.16 pp over strongest baseline | Agentic benchmark; one system, not a Holobiont federation | Similarity alone is inadequate for stateful causal memory |
| An organ can resume from its saved memory after absence | TRACE preprint jointly preserves valid information and rejects stale information on return episodes | Assumes authenticated return, checkpoint and source receipts; degrades with longer absence and has token cost | Strong bounded support for return-time admission |
| A memory write can immediately be shared as truth | MemTX preprint stages writes, validates and commits beliefs, uses isolation levels and gates external actions | LLM path uses weaker gate; provenance gaps and retry escape remain; no environment-level replay | Reject immediate-actionable-write assumption |
| Revoking a memory is equivalent to deleting one record | MemTX uses typed dependency-graph cascade; survey identifies revocation/recovery as sparse research areas | Only recorded lineage is repairable; recovery of actual external effects remains limited | Need typed revocation and recovery closure |
| Message-edge monitoring is enough to protect the organs | MAPLE-Guard and MemoryDojo show memory can propagate across tasks and agents through write/retrieve/promote/reuse paths without a current malicious message | MAPLE-Guard relies on intact metadata/evaluator feedback; MemoryDojo is a preprint and sandbox benchmark | Memory links must be a separate attack/propagation graph |
| Persistent memory is safe if it is summarized | PPMF identifies provenance laundering: untrusted external content can be rewritten as apparent user history or workflow support | Preprint; schema-grounded setting assumes platform-maintained metadata and confirmation | Provenance must survive transformations and latent summaries |
| Majority of organs' memories is a reliable consensus | MANBENCH (ICLR 2026) reports collective false-memory formation across 13 LLMs and five protocols | Multiple-choice benchmark; open-ended team tasks remain untested | Majority agreement is not truth; track evidence ancestry |
| More memory is always better | MemoryDojo finds poison can persist and later harm; some backends lose benign memory utility under poisoning | Synthetic sandbox trajectories; code release pending at paper date | Memory utility and memory risk must be jointly measured |
| Concurrent memory writes can be handled by better prompting | ICML 2026 position paper maps MAS failures to stale reads, lost updates and inconsistent outcomes | Position paper, not empirical proof of a specific protocol | Explicit isolation and conflict control are design requirements to test |
| Collective memory can be repaired after corruption | MemTX and MAPLE-Guard provide bounded repair/gating mechanisms; survey finds only 6 of 89 papers address recovery | Neither demonstrates full recovery of all holders and downstream decisions in a large federation | Recovery closure remains a major open gap |
| A learned Narrative Thread can replace the event history | UMA and causal-graph memory support structured/learned summaries; TRACE and MemTX require source receipts and lineage | No evidence that a latent summary alone preserves source, time, authority and dependencies | Narrative Thread should be a view over governed event state, not sole truth |
| A memory manager should optimize the producer's future task success | Survey finds admission is often producer-authored/producer-scored; collective utility recall is under-measured | Survey's coding is curated and non-causal | Test audience- and team-level utility |
| Memory deletion is a safe way to remove stale information | TRACE shows reset can discard valid information; stale/valid admission is a joint problem | TRACE assumptions and verifier calibration matter | Prefer versioning, supersession, quarantine and revalidation over blind deletion |
| Holobiont collective memory improves over strong single-agent memory | UMA is a strong single-agent proactive-memory baseline; AMA-Agent improves causal state retrieval | No matched-budget comparison with heterogeneous specialist organs | Unvalidated; single-agent memory must be a baseline |

## Status vocabulary
- **Supported in bounded settings:** direct empirical evidence exists within the stated scope.
- **Promising / preprint:** direct evidence exists but is not peer-reviewed or has narrow assumptions.
- **Inference:** an architectural implication from several sources, not directly demonstrated.
- **Unvalidated:** no decisive experiment tests the distinctive Holobiont claim.
- **Rejected:** a broad assumption is contradicted or lacks a valid basis.
