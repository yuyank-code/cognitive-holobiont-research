# Contradictions and Open Problems — Pass 28 (2026-10-18)

## Contradictions sharpened

1. Nominal team size vs independent evidence: interaction can increase correlation, so nominal count can overstate independent evidence.
2. Answer diversity vs correctness: entropy counts distinct outputs, including distinct errors.
3. Conformity vs correction: interaction can expose a correct minority insight or move correct agents toward a wrong modal answer.
4. Small-team extrapolation vs domain transfer: predicting larger teams within one bounded family does not certify tools, long-horizon work, or asymmetric specialists.
5. Persistent-memory null vs absent opportunity: independent-item benchmarks may not permit useful cross-session retrieval; a null there is not proof of universal memory failure.
6. Peak working set vs total cost: lower per-call KV may require more calls and greater cumulative traffic.
7. Adaptive protocol gains vs router overhead: protocol choice can matter, but router cost, failures, and generalization must be measured.
8. Graph attribution vs causal necessity: trace graphs remain diagnostic until interventions change independently verified outcomes.
9. Evidence governance vs over-filtering: admission rules may contain stale/adversarial claims while rejecting valid minority facts.
10. Controller adaptivity vs common-mode failure: a joint router can itself become a shared point of error or attack.

## Open problems
- Test whether effective-team-size estimates predict verified utility on held-out task families.
- Estimate dependence in heterogeneous graphs with shared tools, retrieval, and common-mode failures.
- Test the k-times-rounds equivalence outside homogeneous conformity settings.
- Create memory tasks with genuine cross-session state reuse and clean paired counterfactuals.
- Validate protocol-router gains after counting routing, retries, and verification.
- Test a joint communication/protocol/memory/verification/stopping controller against common-mode failure.
- Preserve useful minority evidence while filtering unsupported claims.
- Establish task-general causal synergy under matched resource, information-access, and privacy constraints.

## Falsification conditions
The Holobiont-specific synergy claim weakens if gains disappear against matched independent multi-output, heterogeneous-ensemble, or adaptive-workflow baselines; if scaling proxies fail on held-out tasks or do not predict utility; if memory benefit is absent in adequately powered tasks with real authorized reuse; if routing gains vanish after total costs; or if apparent gains depend on unequal information access or trace attribution without outcome-changing interventions.
