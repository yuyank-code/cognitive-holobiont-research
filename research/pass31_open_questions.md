# Pass 31 Open Questions

1. Does temporal versioning add value beyond lifecycle governance?
2. Can an update trigger reevaluation of all dependent summaries, plans, and queued actions?
3. How should ambiguous updates be represented?
4. Does routing based on current, supported evidence beat routing based on novelty alone under equal cost?
5. What is the cost of incorrectly retiring still-useful memory?

The main unresolved conflict is that persistent quality governance can improve task performance while temporal supersession remains difficult. Provenance is useful but does not establish truth or freshness. Adaptive communication's one-step surrogate guarantee is not a guarantee of final correctness. Holobiont-specific synergy remains unvalidated.
