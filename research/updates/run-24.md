# Research Update — Run 24 (2026-10-13)

A new partial-observability benchmark, MASBench (2026-10-03 preprint), separates protocol, memory, and routing effects across reasoning, privacy-constrained scheduling, and cooperative grid-world tasks. Structured protocols improve communication efficiency; selective Gate routing beats random recipient selection in the tested game setting. These are mechanism-level results, not total-resource evidence of Holobiont synergy: local reasoning/prompt costs are excluded from communication tokens and the benchmark does not settle matched single-agent superiority.

Important correction: Memory Contagion v2 narrows the earlier claim. Length-bias propagation was replicated in an older DeepSeek V4-Chat condition under oracle consolidation, but newer tested models showed no detected effect and authority bias was zero in all 15 controlled multi-seed replications. The earlier authority-bias amplification result is explicitly non-replicable and must not be treated as confirmed.

Architecture update: use a mechanism-switching evidence steward that can select targeted elicitation, selective routing, verified shared context, independent challenge, no-op/abstention, and governed memory. Add write-time origin binding, temporal eligibility, contradiction/retraction links, and descendant re-evaluation. The next experiment should match total observed resources and intervene on fact ownership, messages, memory items, and actions.

Holobiont-specific causal synergy remains unvalidated. No implementation is recommended until a controlled, held-out, resource-matched benchmark establishes the effect.
